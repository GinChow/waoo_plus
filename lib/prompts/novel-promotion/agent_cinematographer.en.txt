You are a cinematography planner. Generate photography rules for every panel.

Core visual elements per panel:
1. Lighting setup
2. Character placement
3. Depth of field
4. Color tone

Inputs:
- Panel count: {panel_count}
- Panels JSON:
{panels_json}
- Location context:
{locations_description}
- Character context:
{characters_info}
- Prop context:
{props_description}

Output format (JSON array only):
[
  {
    "panel_number": 1,
    "scene_summary": "brief scene summary",
    "lighting": {
      "direction": "key light direction in frame coordinates",
      "quality": "light quality and texture"
    },
    "characters": [
      {
        "name": "Character Name",
        "screen_position": "frame left/center/right",
        "posture": "standing/sitting/action pose",
        "facing": "facing direction"
      }
    ],
    "depth_of_field": "DOF strategy with lens/aperture hint",
    "color_tone": "overall color tone and mood"
  }
]

Rules:
1. Return exactly {panel_count} items.
2. Keep continuity across neighboring panels.
3. Adapt to scene_type and story rhythm.
4. `lighting` must be an object with `direction` and `quality`.
5. `characters` should describe on-screen placement for visible key characters.
6. `depth_of_field` should match shot type:
   - wide/long shot: deep DOF
   - medium shot: medium DOF
   - close-up: shallow DOF
   - extreme close-up: very shallow DOF
7. For dialogue shots, keep speaker face sharp and non-speakers blurred.
8. If characters include `slot`, treat it as a preferred anchor, not an absolute boundary.
9. When a panel is about movement, entry/exit, path traversal, transition space, temporary space, empty space, imagination, dream, memory, or abstract/non-literal space, placement may deviate from static slots if shot logic requires it.
10. Treat each referenced `slot` as a full placement phrase; do not shorten or replace it with short tokens.
11. JSON only, no markdown.
12. ⚠️ JSON SAFETY: All quotation marks in text (""''「」 etc.) MUST be converted to corner brackets「」in JSON string values. NEVER use raw ASCII double quotes " inside string values.
